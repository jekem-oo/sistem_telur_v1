PANDUAN LENGKAP MENJALANKAN SISTEM GRADING TELUR BERBASIS FLUTTER & AI GEMINI
(Sistem Klasifikasi Kualitas Telur Candling Sinar Merah SNI 3926:2008 & USDA)

Selamat datang di kode sumber resmi Flutter untuk Sistem Grading Mutu Telur.
Aplikasi ini mendukung platform Android, iOS, Windows, macOS, dan Web.

------------------------------------------------------------------------------
1. PRASYARAT SISTEM
------------------------------------------------------------------------------
Sebelum memulai, pastikan perangkat Anda telah terpasang:
- Flutter SDK (Versi >= 3.19.0 disarankan)
  Cek dengan perintah: flutter --version
- Dart SDK (Versi >= 3.0.0)
- Android Studio / VS Code dengan ekstensi Flutter & Dart
- Perangkat Android fisik atau Emulator dengan kamera aktif
- Google Gemini API Key (Bisa didapatkan gratis di https://aistudio.google.com/)

3. LANGKAH-LANGKAH MENJALANKAN APLIKASI
------------------------------------------------------------------------------

Langkah 1: Masuk ke direktori proyek
  Buka Terminal / Command Prompt lalu jalankan:
  cd flutter_app

Langkah 2: Ambil semua dependensi library
  flutter pub get

Langkah 3: Hubungkan HP Android / Buka Emulator
  Pastikan perangkat Anda terdeteksi dengan perintah:
  flutter devices

Langkah 4: Jalankan aplikasi dengan memasukkan API Key Gemini
  Ganti 'MASUKKAN_GEMINI_API_KEY_ANDA' dengan kunci API Anda dari Google AI Studio:

  flutter run --dart-define=GEMINI_API_KEY=MASUKKAN_GEMINI_API_KEY_ANDA

  Catatan untuk pengguna VS Code / Android Studio:
  Anda juga dapat mengatur --dart-define di file launch.json atau Run Configuration.

------------------------------------------------------------------------------
4. KONFIGURASI IZIN KAMERA (PENTING!)
------------------------------------------------------------------------------

A. Untuk Android:
   Pastikan file 'android/app/src/main/AndroidManifest.xml' memiliki baris berikut
   di dalam tag <manifest>:
   
   <uses-permission android:name="android.permission.CAMERA" />
   <uses-permission android:name="android.permission.INTERNET" />
   <uses-feature android:name="android.hardware.camera" />
   <uses-feature android:name="android.hardware.camera.autofocus" />

B. Untuk iOS:
   Buka 'ios/Runner/Info.plist' dan tambahkan baris berikut di dalam <dict>:

   <key>NSCameraUsageDescription</key>
   <string>Aplikasi memerlukan akses kamera untuk menganalisa citra candling telur.</string>
   <key>NSMicrophoneUsageDescription</key>
   <string>Aplikasi tidak menggunakan mikrofon.</string>

5. LOGIKA ATURAN MUTU & TAKSONOMI TELUR (SNI 3926:2008)
------------------------------------------------------------------------------
Aplikasi mengimplementasikan kaidah evaluasi:

1. GRADE A (Sangat Segar):
   - Kedalaman kantung udara <= 3.5 mm
   - Cangkang mulus utuh tanpa noda atau retakan
   - Kuning telur berada tepat di tengah (sentris)
   - Transmisi sinar merah 640nm tembus sempurna tanpa bayangan gelap

2. GRADE B (Segar / Konsumsi):
   - Kedalaman kantung udara 3.5 mm s/d 6.0 mm
   - Kuning telur agak bergeser dari tengah tapi masih mobile bebas
   - Layak konsumsi dapur atau rumah tangga

3. GRADE C (Pengolahan / Industri):
   - Kedalaman kantung udara 6.0 mm s/d 9.0 mm
   - Kuning telur bergerak bebas menyentuh dinding cangkang
   - Peruntukan industri roti, kue, atau pakan

4. GRADE D (AFKIR / REJECT - MUTLAK):
   - PERATURAN MUTLAK: Bila ada retak rambut (hairline crack), retak bocor,
     noda darah (blood spot / meat spot), cincin embrio mati (blood ring),
     kantung udara > 9.0 mm, cangkang abnormal kalsium, atau busuk,
     MAKA STATUS MUTLAK ADALAH GRADE D (AFKIR).
   - Selain kriteria Grade A, Grade B, dan Grade C -> MUTLAK GRADE D.
